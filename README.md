# REDME1
Utwóż klase MySqlDB która dziedziczy po klasie abstrakcyjnej Database 
Właściwości, metody oraz metody abstrakcyjne.
dałać do classy MySqlDB interface, dołąć interface SQLinterface do MySqlDB 
abstrakcyjna klassa powinna zawierać odpowiednie właśćiwośći do połączenie się z bazą dannych za pomocą funkcji MySqli connect 
abstrakcyjna klassa Badabase powinna zawierać odpowiedne metody do operowania na CRUD
1. tworzenie bazy dannych
2. tworzenie tabeli
3. odczytywanie z tabeli dannych
4. aktualizacja tabeli
5. usuwanie tabeli

interface Sqlinterface ma rozszeżać implementować metody takie jak: find all, find, read one, read.firstten 


wszystkie metody objectu MySqlDB mają być sprawdzone, i wywpłane w codzie
!dodatkowe punkty będą uwzglednione za implementacje własnej metody yestującej poprawność działania metod naszego objectu
